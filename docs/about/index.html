About

關於 arammeta

ARAM Mayhem 的獨立資料工具、統計方法與開源資訊。

最後更新：2026-07-15

本站提供什麼

arammeta 將 ARAM: Mayhem 對戰整理成英雄、增幅、裝備與隊伍搭配資料，並提供 Draft 分析與 Meta Pick 小遊戲。目標是讓玩家在短時間內看懂版本環境，同時保留樣本量與統計限制。

資料怎麼來

資料由本機 League Client 介面收集，網站只發布彙總後的對戰統計。公開資料不包含 PUUID、Riot ID、召喚師名稱或可識別個別玩家的原始紀錄。

  • 對局以 game ID 去除重複。
  • 英雄勝率使用 Bayesian shrinkage，降低小樣本造成的極端波動。
  • 版本、樣本數與更新日期會顯示在資料旁，跨版本結果不視為同一環境。

如何解讀

勝率代表歷史資料中的關聯，不保證個別對局結果。英雄強度、玩家熟練度、隊伍組成、增幅選擇與版本平衡都會影響結果。樣本較少的組合應視為探索線索，不應當成確定答案。

開源與回報

網站與資料處理工具公開於 GitHub。你可以檢查方法、提出資料問題或回報介面錯誤。
