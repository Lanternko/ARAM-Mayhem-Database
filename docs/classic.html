資料與限制

英雄 Tier 使用 Beta 收縮後的勝率（先驗 50%、強度 200 場），避免小樣本被偶然高勝率放大。常見分路以每位英雄在 LCU timeline.lane／role 中最多的分類為主要分路；次高分類至少要有 50 筆、且占該英雄有效分路紀錄 15%，才列為次要分路，最多顯示兩個。這是舊版客戶端推估訊號，不是精確的 teamPosition，適合做整體篩選，不應當成單場位置真值。裝備資料是終局背包中的持有關聯，沒有購買時間線，因此不應解讀為出裝順序、因果效果或直接推薦。

戰鬥輪廓是每場或每分鐘的描述統計。最佳搭檔與棘手對手只納入至少 100 場的組合，並以 100 場虛擬樣本向雙方英雄強度所推得的預期勝率收縮；它仍是完整 5v5 對局中的關聯，不是單線對決、因果效果或勝率保證。現有資料沒有符文與裝備購買時間線，因此本頁不顯示或推測這兩項。
