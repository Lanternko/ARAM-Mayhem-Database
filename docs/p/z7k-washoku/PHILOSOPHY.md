# 和色 Zen 設計哲學（preview）

色庫來源：[NIPPON COLORS](https://nipponcolors.com/)（整庫挑選，**非**單一色錨）  
資料對照：`nippon-colors` 250 色 JSON（與站上傳統色名一致）

## 鐵則

1. **大面積克制。** 背景／面板／字色只用鼠·墨·練系；高強度只在需要注意時。
2. **背景先定。** 決定氣氛：墨底、藍墨茶面、銀鼠次要字、白練主字。
3. **色彩語言必有，但標準化：**
   - **平行語言**（職業）：同飽和度，只轉色相  
   - **同系強度**（勝率／選用／tier）：1～2 色相，改深淺與飽和  
4. **Filter 三要素**（框／內底／字）只服務「強／弱、多／少」  
   - 峰：白底 + 黑字 + 色框  
   - 高：色底 + 白字  
   - 中低：透明底 + 降飽和字  
5. **禁止：** 無意義漸層、紫霧光暈、大面積高飽和、把功能語意砍成同一色相。
