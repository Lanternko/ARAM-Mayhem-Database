如何阅读这份 Tier List

胜率、贝氏修正、样本数与分级门槛怎么算、怎么读，以及这些数字不能回答什么。

发布日期：2026-06-27

这份 tier list 把英雄依“贝氏修正后的胜率”分级，而不是单纯的原始胜率。原因很简单：小样本的原始胜率非常不稳。这篇说明每个数字怎么算、该怎么读，以及它不能回答什么问题。

资料从哪里来

Riot 的公开 API 不提供 Mayhem 大乱斗（queue 2400）的对局，所以一般的统计网站拿不到这个模式的资料。arammeta 的对局由玩家在自己电脑上的 League Client 收集，再整理成汇总统计。每一场记录双方各五位玩家的英雄、海克斯、装备与胜负，并用 Riot 的对局编号去除重复，同一场不会因为被多位玩家贡献而重复计算。网站只发布汇总后的数字，不公开任何玩家的身分资讯。

三个关键栏位

  • 胜率：经贝氏收缩后的估计值，样本越少越会被拉回整体基准。
  • 场次：样本数，决定你该多相信这个数字。
  • 原始胜率：未修正的真实胜率，和上面对照看落差。

当原始胜率很高、但场次很低时，修正后的胜率会明显被往下压 — 这是刻意的保守，避免你追到只打了几场的假强势。

为什么不直接用原始胜率

胜负是机率事件。一只真实胜率 50% 的英雄，只打 100 场时，光靠运气就可能落在 40% 到 60% 之间；打到 10,000 场，范围才会缩到大约 49% 到 51%。如果直接照原始胜率排名，榜首永远是“刚好手气好的冷门英雄”，而不是真的强的英雄。

贝氏收缩的做法是替每只英雄加上一批“假想场次”，这些场次的胜率等于基准值：

修正胜率 =（实际胜场 + 假想场次 × 基准胜率）÷（实际场次 + 假想场次）

举例：假想场次设为 350、基准 50%。一只打了 100 场、赢 62 场的英雄，原始胜率 62%，修正后是（62 + 175）÷（100 + 350）≈ 52.7%。同样 62% 但打了 10,000 场的英雄，修正后仍有 61.6%。样本够大时，修正几乎不改变数字；样本小时，它挡住杂讯。

新版本刚上线、对局还不多的时候，英雄的基准会暂时参考上一个版本的表现；等本版累积到足够场次，就完全以本版资料为准，避免旧版本盖掉真正的平衡改动。

分级门槛

  • OP：修正胜率 55% 以上
  • T1：52% 以上
  • T2：50% 以上
  • T3：48% 以上
  • T4：46% 以上
  • T5：低于 46%

门槛是固定的胜率数字，不是“前几名”。因此每一级的英雄数量会随版本变动：一个版本可能有很多 OP，另一个版本可能一只都没有。相邻两级之间的差距只有 2 个百分点，贴著门槛的英雄换一批资料就可能升降一级，不必过度解读。

海克斯的数字怎么读

英雄页里的海克斯不是看“拿了这个海克斯的胜率”，而是看它相对于该英雄自身基准的差距（lift）。一只本来就 56% 胜率的英雄，任何海克斯看起来都很强；只有扣掉英雄本身的胜率，才看得出海克斯自己贡献了多少。

海克斯另外有一个方向问题：有些海克斯是在“已经赢的局”才容易被选到或发挥，胜率高不代表选了就会赢。排名因此同时看修正后的差距与选取率，样本太少的组合不会列出来。

这些数字不能回答什么

  • 单场胜负：55% 的意思是 100 场大约赢 55 场，不是这一场会赢。
  • 你个人的表现：数字是所有玩家的平均。高操作门槛的英雄，平均胜率会低估熟练玩家的表现。
  • 因果关系：统计描述的是历史对局中的关联。队伍组成、对手阵容、海克斯选择都会同时影响结果。
  • 跨版本比较：每个数字都标示版本。平衡改动后，上一版的结论不一定成立。

实际使用建议

先看分级，再看场次。OP 与 T1 的英雄在这个模式的平均表现明显较好；T3 上下的英雄差异很小，选自己熟的通常比追半个百分点有用。点开英雄页后，优先看差距大、场次也多的海克斯与装备；差距大但场次少的组合，把它当成值得一试的假设，而不是结论。
