銳兒在短局（16 分鐘內）與長局（22 分鐘以上）的勝率差為 +0.2 個百分點，在全英雄中屬於前後期平衡。

陣容方面，銳兒在消耗型隊伍中勝率較好（+0.7 個百分點），在衝排型隊伍中較差（−1.0 個百分點）。

數據來源為台服 Mayhem（queue 2400）實戰對局。勝率經 Bayesian 收縮調整，以降低小樣本的誤差；所有數字都是歷史對局的關聯，不是單場勝負的保證。
