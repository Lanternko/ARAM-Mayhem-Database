淣菈 大亂鬥分析

淣菈在 Mayhem 大亂鬥（26.23 版本）的 Bayesian 調整勝率為 52.4%，在 173 位英雄中排第 28 名，樣本 43,073 場。屬於目前版本的強勢英雄。

稜彩增幅裡，淣菈表現最好的是寶石手套（60.3%，2,514 場）、基本功夫（59.4%，1,059 場）、阿福英雄（57.3%，774 場）；相對地，衝鋒（45.1%，598 場）、無限循環（47.0%，396 場）在淣菈身上勝率偏低，三選一時可以優先避開。

常見但勝率偏低的裝備：那歐閃刃有 30% 的淣菈對局會出，勝率比淣菈平均低 1.3 個百分點；殞落王者之劍有 21% 的淣菈對局會出，勝率比淣菈平均低 1.5 個百分點。這是歷史關聯，可能反映對局情境（例如落後時才補的裝），不一定是裝備本身不好。

淣菈在短局（16 分鐘內）與長局（22 分鐘以上）的勝率差為 −1.0 個百分點，在全英雄中屬於前後期平衡。

陣容方面，淣菈在衝排型隊伍中勝率較好（+0.8 個百分點），在物理後排型隊伍中較差（−1.6 個百分點）。

數據來源為台服 Mayhem（queue 2400）實戰對局。勝率經 Bayesian 收縮調整，以降低小樣本的誤差；所有數字都是歷史對局的關聯，不是單場勝負的保證。
